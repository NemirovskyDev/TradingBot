# TradingBot Front Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Painel web estático que lê os JSON do backtest e mostra métricas, gráfico com compras e saídas explicadas, operações, risco e glossário.

**Architecture:** App React em `web/`, sem backend. Camada `data` valida e carrega JSON; componentes de tela por pasta; gráficos com Lightweight Charts atrás de funções puras testáveis; animações centralizadas em `motion/`.

**Tech Stack:** React 18, Vite, TypeScript (strict), `lightweight-charts@^4.2.0`, `motion`, Vitest, Testing Library, `vitest-axe`, ESLint.

**Spec:** `docs/superpowers/specs/2026-10-28-front-design.md` (contrato de dados na seção 5). Contexto: `PRODUCT.md`.

## Global Constraints
- Superfície Operate, direção "padrão da categoria" (régua: TradingView, Robinhood, Stripe Dashboard, Linear), sem fantasia.
- Sem backend, sem chaves, sem dados fora dos JSON de `public/data`; nada hardcoded na interface além de textos fixos.
- Aviso fixo em todas as telas: "Simulação com dados de exemplo. Não é recomendação de investimento." Execução com `meta.synthetic` mostra o selo "exemplo".
- Português do Brasil; números no formato pt-BR (`12,4%`, `512,40`, datas `dd/mm/aaaa`).
- Contraste AA: texto usa verde `#13734a`, vermelho `#b3261e`, laranja `#c2410c` ou mais escuros sobre fundo claro; compra e saída também por forma e texto, nunca só por cor.
- Animações livres via módulo `motion/`, mas com `prefers-reduced-motion` desligando-as e nenhum conteúdo escondido atrás delas.
- Roteamento por hash; `base` do Vite `/TradingBot/`; atribuição visível do TradingView (Lightweight Charts, Apache-2.0).
- Fontes e tokens finais: escolhidos na construção com o Impeccable, fora da lista de fontes genéricas que o detector marca, e registrados em `DESIGN.md`.
- Todo código passa pela pipeline de qualidade do CLAUDE.md (Task 10). Commits e push só com OK do Bernardo; deploy no GitHub Pages só com OK.

## Review Focus
- JSON malformado, campo faltando ou `schema` diferente de 1: erro claro com botão de tentar de novo, nunca tela em branco.
- Execução sem trades ou série com 1 ponto: gráficos e tabela mostram estado vazio explicado, sem exceção.
- Texto longo de motivo e tabela em 390 px: sem corte nem rolagem horizontal da página.
- Retornos como fração (0,124) exibidos como `12,4%`, incluindo negativos (`−8,2%` com sinal de menos tipográfico) e zero.
- `prefers-reduced-motion: reduce`: contagem de números e entradas aparecem já no valor final.
